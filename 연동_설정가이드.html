고객카드 → Google Sheet 연결

GitHub Pages 정적 페이지 · 서버 없이 Apps Script 중계 · 약 15분

전체 흐름

태블릿에서 github.io 폼 작성 → 숨은 iframe 으로 Apps Script 웹앱에 POST → Apps Script 가 서명은 Drive 에 PNG 로, 나머지는 Sheet 한 줄로 저장 → 접수번호를 폼에 되돌려줌.
서버도, 데이터베이스도, 월 비용도 없습니다.

1스프레드시트와 폴더 만들기

  1. Google Drive 에서 새 스프레드시트 생성 → 이름 예: 구름왁싱 고객카드
  2. 주소창에서 ID 를 복사합니다.
    docs.google.com/spreadsheets/d/1AbC...XyZ/edit → 굵은 부분
  3. Drive 에 새 폴더 생성 → 이름 예: 고객서명
  4. 폴더를 열고 주소창에서 ID 복사.
    drive.google.com/drive/folders/1DeF...UvW → 굵은 부분

폴더와 시트는 절대 "링크가 있는 모든 사용자"로 공유하지 마세요. 본인 계정만 접근 가능한 기본 상태로 두면 됩니다. Apps Script 는 소유자 권한으로 실행되므로 공유하지 않아도 정상 저장됩니다.

2Apps Script 붙여넣기

  1. 스프레드시트에서 확장 프로그램 → Apps Script
  2. 기존 코드를 전부 지우고 Code.gs 파일 내용을 붙여넣습니다
  3. 맨 위 세 줄을 채웁니다
const SHEET_ID  = '1AbC...XyZ';        // 1단계에서 복사한 시트 ID
const FOLDER_ID = '1DeF...UvW';        // 1단계에서 복사한 폴더 ID
const TOKEN     = 'gureum-2026-x7k9qp'; // 아무 문자열, 20자 이상 권장
  1. 저장 후 함수 목록에서 설치테스트 를 골라 실행
  2. 권한 승인 창이 뜹니다 → 고급 → (안전하지 않음) 이동 → 허용
    본인이 만든 스크립트라 정상입니다
  3. 실행 로그에 시트 연결 OK / 폴더 연결 OK 가 나오면 성공

3웹앱으로 배포

  1. 우측 상단 배포 → 새 배포
  2. 톱니바퀴 → 웹 앱 선택
항목설정값이유
설명고객카드 v1—
실행 계정나시트·폴더 접근 권한이 필요
액세스 권한모든 사용자고객이 로그인 없이 제출해야 함
  1. 배포 → 나오는 웹 앱 URL 을 복사
    https://script.google.com/macros/s/AKfy.../exec

코드를 고칠 때마다 재배포해야 합니다

배포 → 배포 관리 → 연필(수정) → 버전: 새 버전 → 배포
"새 배포"로 만들면 URL 이 바뀌어 폼도 같이 고쳐야 하니, 수정할 때는 기존 배포를 수정하세요.

card_form.html 을 편집기로 열고 위쪽 두 줄을 바꿉니다.

const ENDPOINT = 'https://script.google.com/macros/s/AKfy.../exec';

저장 후 GitHub 저장소에 올립니다. 기존 구조에 맞추면:

kwonjunhyuk0/public/

├─ 3d/store/index.html

주소는 kwonjunhyuk0.github.io/public/card/ 가 됩니다. 태블릿 홈 화면에 추가해두면 앱처럼 열립니다.

6꼭 알아두실 것

이 폼은 건강정보를 다룹니다

임신 여부, 복용 약, 알레르기, 피부질환은 개인정보보호법상 민감정보로 분류될 가능성이 높습니다. 폼에서 별도 동의를 받도록 만들어두었지만, 실제 운영에는 두 가지가 더 필요합니다.

  • 국외 이전 고지 — Google 서버는 해외에 있습니다. 개인정보 처리방침에 이전 국가·목적·항목을 적어야 합니다
  • 개인정보 처리방침 게시 — 폼에서 링크로 연결되어야 합니다

URL 을 아는 사람은 누구나 제출할 수 있습니다

TOKEN 이 HTML 소스에 들어 있으므로 완벽한 인증이 아닙니다. 자동 봇 스팸은 막지만, 소스를 본 사람은 가짜 데이터를 넣을 수 있습니다. 시트에 이상한 줄이 쌓이면 TOKEN 을 바꾸고 재배포하세요 (HTML 도 같이).

보관 기간을 지키셔야 합니다

폼에 "최종 방문일로부터 3년" 이라고 고지했습니다. 3년 지난 행과 서명 파일은 실제로 지우셔야 합니다. 시트에 접수시각 열이 있으니 정렬해서 주기적으로 정리하세요.

잘 만들어진 부분

  • 서명을 시트에 넣지 않고 Drive 링크로 — 셀 5만자 제한을 넘지 않습니다
